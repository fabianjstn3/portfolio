# Security Policy

## Supported Scope
This repository hosts a static portfolio web application (`index.html`, `style.css`, `script.js`) deployed on Vercel and GitHub Pages.

## Reporting a Vulnerability
If you discover a security issue (such as a Content Security Policy bypass, DOM XSS vector, or unsafe external link), please report it responsibly via:

- LinkedIn: https://www.linkedin.com/in/justine-fabian/
- GitHub: https://github.com/fabianjstn3

Please include:
1. A clear description of the issue and affected file/line.
2. Steps to reproduce or a minimal proof-of-concept.

We aim to acknowledge reports within 48 hours and remediate verified issues promptly.
